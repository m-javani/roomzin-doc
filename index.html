How It Routes

One global inventory service. Distributed underneath.

All components get routing info from RzID — a lightweight service registry.

RzPoint is a customer provided service that resolves IDs to hostnames

How a Request Travels

SDK/RzGate → Edge Router (segment-based zone routing) → Zone Router (segment-based shard routing) → RzBridge (leader/follower routing) → Roomzin

The application never knows which zone, shard, bridge, or Roomzin node handled the request.
