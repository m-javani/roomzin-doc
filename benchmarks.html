Snapshot Performance

Compact snapshots enable fast saves and reloads. Compressed snapshots are ~92 MB for 60M records.

Records Load Time Raw CSV Size Snapshot (compressed) Memory Usage
60M records 3,041 ms 5.3 GB 92 MB ~4.1 GB

The in-memory footprint is 4.1 GB, which is ~77% of the raw CSV data size (5.3 GB)

In Production

  • Multiple read replicas (follower nodes) provide better results
  • RzGate independent scaling provides higher TPS for HTTP clients
  • More cores provide better parallelism. Segments are processed in parallel.
